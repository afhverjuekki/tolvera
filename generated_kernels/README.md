# Generated Kernels Repository

This directory contains Taichi kernels and functions that have been successfully generated by the LLM and passed validation. These kernels are automatically accumulated for future reference and reuse.

## Structure

Each kernel is saved with:
- A unique function name (original name + UUID suffix to avoid conflicts)
- A docstring containing metadata:
  - UUID: Unique identifier for this kernel
  - Original Name: The original function name before uniquification
  - Prompt: The natural language prompt that generated this kernel
  - Model: The LLM model used for generation
  - Type: Either "expert" or "integration" kernel
  - Generated: Timestamp of when the kernel was generated
  - Additional metadata specific to the kernel type

## Usage

The kernel accumulator is automatically integrated into the synthesis flow:

```python
from tolvera.llm.poe_synthesis import PoEExpertSynthesizer

# Kernels are automatically saved when synthesis succeeds
synthesizer = PoEExpertSynthesizer(
    model_name="qwen2.5:3b",
    accumulator_path="generated_kernels/kernels_repository.py"
)

# Generate and automatically save a kernel
result = await synthesizer.synthesize_expert("particles attract each other")
if result["success"]:
    print(f"Kernel saved with UUID: {result['kernel_uuid']}")
```

## Searching Kernels

You can search for previously generated kernels:

```python
from tolvera.llm.kernel_accumulator import KernelAccumulator

accumulator = KernelAccumulator("generated_kernels/kernels_repository.py")

# Load all kernels
all_kernels = accumulator.load_kernels()

# Search for specific patterns
matches = accumulator.search_kernels("attract")
```

## Benefits

1. **Reusability**: Successfully generated kernels can be referenced by future LLM interactions
2. **Learning**: The LLM can learn from previously successful implementations
3. **Debugging**: Failed generations can be compared against successful ones
4. **Version History**: Track how kernels evolve over time with different prompts
