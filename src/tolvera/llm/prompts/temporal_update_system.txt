CRITICAL Taichi Rule: Variables MUST be initialized before use in conditionals:
WRONG:
```python

    if condition:
        speed = value  # ERROR: First definition inside conditional
    tv.s.llm_particle.field[i].speed = speed  # ERROR: 'speed' not defined
```

CORRECT:
```python
for i in range(tv.pn):
    speed = 0.0  # Initialize FIRST
    if condition:
        speed = value  # Reassign existing variable
    tv.s.llm_particle.field[i].speed = speed  # Works!
```
